## 잠금 규칙 요약

이 시스템에는 편집이 막히는 지점이 두 곳 있습니다. 헷갈리기 쉬우니 먼저
정리합니다.

| 잠기는 것 | 언제 | 왜 | 푸는 법 |
| :--- | :--- | :--- | :--- |
| **페르소나 · 구성 스냅샷** | 그 대화의 첫 메시지 | 시작한 대화가 자기완결적이어야 함 | 안 풀림 (설정 갱신 버튼으로 재동결만) |
| **로스터 편집 (전역)** | **아무** 대화든 토론 진행 중 | 에이전트 풀은 프로세스 전체가 공유 | 토론이 끝나면 자동 해제 |

두 번째가 놀라운 지점입니다. 다른 대화에서 토론이 돌고 있으면 **지금 보고 있는
빈 대화에서도** 에이전트를 추가할 수 없습니다. 풀을 갈아 끼우면 진행 중인 턴의
발언자 목록이 바뀌기 때문입니다.

작업 공간과 라운드 수, 전략은 이 잠금과 무관합니다 — 대화 하나의 설정입니다.
